---
title: "List activity"
api: "GET /v1/users/{id}/activity"
description: "Returns a user's ledger of deposits, buys, sells and withdrawals, newest first."
---

Activity combines orders and money movements into one feed. Open orders are included, so it also shows what's pending.

## Path parameters

<ParamField path="id" type="string" required>
  The user's id.
</ParamField>

## Query parameters

<ParamField query="limit" type="integer">
  How many entries to return, from 1 to 200.
</ParamField>

## Returns

<ResponseField name="object" type="string">
  Always `list`.
</ResponseField>
<ResponseField name="user_id" type="string">
  The user the activity belongs to.
</ResponseField>
<ResponseField name="data" type="object[]">
  <Expandable title="properties" defaultOpen>
    <ResponseField name="id" type="string">
      The id of the order (`ord_`) or funding transaction (`fund_`) behind the entry.
    </ResponseField>
    <ResponseField name="type" type="string">
      `deposit`, `withdrawal`, `buy` or `sell`.
    </ResponseField>
    <ResponseField name="status" type="string">
      The status of the order or transaction.
    </ResponseField>
    <ResponseField name="asset" type="string">
      The instrument or currency involved.
    </ResponseField>
    <ResponseField name="amount" type="string">
      Units of `asset`.
    </ResponseField>
    <ResponseField name="value_usd" type="string">
      Value in US dollars.
    </ResponseField>
    <ResponseField name="description" type="string">
      A sentence describing the entry.
    </ResponseField>
    <ResponseField name="leveraged" type="object | null">
      Set for leveraged orders: `direction`, `leverage` and `action`.
    </ResponseField>
    <ResponseField name="order_type" type="string">
      For orders: `market`, `limit`, `stop`, `stop_limit` or `take_profit`.
    </ResponseField>
    <ResponseField name="limit_price_usd" type="string | null">
      For orders that have one.
    </ResponseField>
    <ResponseField name="trigger_price_usd" type="string | null">
      For orders that have one.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      When the entry was created.
    </ResponseField>
  </Expandable>
</ResponseField>

