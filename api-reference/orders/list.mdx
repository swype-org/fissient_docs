---
title: "List a user's orders"
api: "GET /v1/users/{id}/orders"
description: "Returns a user's orders, newest first."
---

## Path parameters

<ParamField path="id" type="string" required>
  The user's id.
</ParamField>

## Query parameters

<ParamField query="status" type="string">
  Return only orders with this status. Use `open` to show pending limit and stop orders.
</ParamField>

## Returns

A list of [order objects](/api-reference/orders/retrieve).

<RequestExample>
  ```bash cURL
  curl "https://invest-api.blink.cash/v1/users/usr_01M761XYYTGZK43AP9XK0WKQ97/orders?status=open" \
    -H "Authorization: Bearer $FISSIENT_KEY"
  ```
</RequestExample>
