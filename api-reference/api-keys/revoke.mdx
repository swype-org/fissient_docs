---
title: "Revoke an API key"
api: "POST /v1/api-keys/{id}/revoke"
description: "Permanently disables a key."
---

A revoked key fails with `401 invalid_api_key` from then on. Revoking can't be undone. To rotate a key, create the replacement first, switch over, then revoke the old one.

## Path parameters

<ParamField path="id" type="string" required>
  The key's id, such as `key_01M761YWWKJQEEVJXD30308GSX`. This is the id, not the secret.
</ParamField>

## Returns

The [API key object](/api-reference/api-keys/create), with `revoked_at` set.

<RequestExample>
  ```bash cURL
  curl -X POST https://invest-api.blink.cash/v1/api-keys/key_01M761YWWKJQEEVJXD30308GSX/revoke \
    -H "Authorization: Bearer $FISSIENT_KEY"
  ```
</RequestExample>

<ResponseExample>
  ```json 200
  {
    "id": "key_01M761YWWKJQEEVJXD30308GSX",
    "object": "api_key",
    "scope": "agent",
    "prefix": "ak_test_kSj1",
    "label": "assistant",
    "livemode": false,
    "created_at": "2026-11-11T19:39:35.699Z",
    "revoked_at": "2026-11-11T19:41:34.165Z"
  }
  ```
</ResponseExample>
