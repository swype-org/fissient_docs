---
title: "Complete a pending deposit"
api: "POST /v1/sandbox/funding/{id}/complete"
description: "Simulates a pending transfer arriving, or failing."
---

Sandbox only. A live key gets `403 sandbox_only`.

Use this to test orders that wait for money. When an order is `awaiting_funding`, its `funding_instructions.funding_id` is the transfer it's waiting for. Complete that transfer here and the order continues.

## Path parameters

<ParamField path="id" type="string" required>
  The funding transaction's id, such as `fund_01M7620P0TBYG100GE9331FY4Z`.
</ParamField>

## Body

<ParamField body="status" type="string" default="completed">
  `completed` to simulate the money arriving, or `failed` to simulate it not arriving.
</ParamField>

## Returns

The updated [funding transaction](/api-reference/funding/withdraw#the-funding-transaction-object).

<RequestExample>
  ```bash cURL
  curl https://invest-api.blink.cash/v1/sandbox/funding/fund_01M7620P0TBYG100GE9331FY4Z/complete \
    -H "Authorization: Bearer $FISSIENT_KEY" \
    -H "Content-Type: application/json" \
    -d '{ "status": "completed" }'
  ```
</RequestExample>
