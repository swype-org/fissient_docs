---
title: "List instruments"
api: "GET /v1/instruments"
description: "Returns the catalog with live prices and rates."
---

Pass `user_id` to include that user's eligibility on each instrument, which gives you everything a catalog screen needs in one call.

## Query parameters

<ParamField query="asset_class" type="string">
  Filter by class: `equity`, `gold`, `crypto`, `lending_yield`, `treasury_yield` or `cash`.
</ParamField>

<ParamField query="user_id" type="string">
  Adds an `eligibility` object to each instrument for this user.
</ParamField>

## Returns

A list of [instrument objects](/api-reference/instruments/retrieve).

<RequestExample>
  ```bash cURL
  curl "https://invest-api.blink.cash/v1/instruments?asset_class=gold" \
    -H "Authorization: Bearer $FISSIENT_KEY"
  ```
</RequestExample>
