---
title: "Stream events"
api: "GET /v1/events"
description: "A live stream of your events over Server-Sent Events."
---

The stream delivers the same events as webhooks, without you hosting a receiver. It suits local development, scripts and agents.

The response is `text/event-stream` and stays open. Each message has:

- `id`: the event's id
- `event`: the event type, such as `order.updated`
- `data`: the event as JSON

Without a cursor, the stream starts from now. A comment line is sent every 15 seconds to keep the connection alive. Each API key can hold up to five streams at once. A sixth returns `429 too_many_streams`.

## Query parameters

<ParamField query="after" type="string">
  Resume after this event id. You can send the `Last-Event-ID` header instead, which `EventSource` clients do automatically when they reconnect.
</ParamField>

<RequestExample>
  ```bash cURL
  curl -N https://invest-api.blink.cash/v1/events \
    -H "Authorization: Bearer $FISSIENT_KEY"
  ```

  ```javascript Node.js
  const res = await fetch("https://invest-api.blink.cash/v1/events", {
    headers: { Authorization: `Bearer ${process.env.FISSIENT_KEY}` },
  });

  const decoder = new TextDecoder();
  let buffer = "";

  for await (const chunk of res.body) {
    buffer += decoder.decode(chunk, { stream: true });
    const messages = buffer.split("\n\n");
    buffer = messages.pop();

    for (const message of messages) {
      const data = message.split("\n").find((line) => line.startsWith("data: "));
      if (data) handle(JSON.parse(data.slice(6)));
    }
  }
  ```
</RequestExample>
