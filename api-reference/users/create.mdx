---
title: "Create a user"
api: "POST /v1/users"
description: "Creates a user and opens their investing account."
---

Create one user for each of your customers. The user's account is ready as soon as this call returns.

US residents and US nationals are refused with `422 us_person`.

## Body

<ParamField body="partner_user_ref" type="string" required>
  Your own id for this customer, up to 128 characters. Must be unique. A second user with the same reference returns `409 user_already_exists`.
</ParamField>

<ParamField body="residence_country" type="string" required>
  Two-letter country code of where the user lives, such as `BR`.
</ParamField>

<ParamField body="nationality" type="string" required>
  Two-letter country code of the user's nationality.
</ParamField>

<ParamField body="investor_type" type="string" required>
  `retail` or `professional`.
</ParamField>

<ParamField body="kyc_attested" type="boolean" required>
  `true` if you've verified this person's identity. Users who aren't attested can't buy.
</ParamField>

<ParamField body="display_currency" type="string" default="USD">
  Three-letter currency code used for display values, such as `BRL`.
</ParamField>

<ParamField body="policy" type="object">
  Optional [guardrails](/concepts/guardrails) for the user.

  <Expandable title="properties">
    <ParamField body="max_order_usd" type="string">
      Largest single order allowed.
    </ParamField>
    <ParamField body="approval_threshold_usd" type="string">
      Orders above this wait for the user's approval.
    </ParamField>
    <ParamField body="max_leverage" type="string">
      Whole number from 1 to 100 capping leverage.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="linked_home_wallet" type="object">
  The user's existing wallet in your app, if you have one. See [Link a wallet](/api-reference/users/link-wallet).
</ParamField>

## Returns

The [user object](/api-reference/users/retrieve).
